# Privacy Policy

Last updated: October 19, 2026

Firefox OneNote Quick Save sends content to the OneNote desktop app installed
on the user's Windows computer. The extension does not send that content to
the project maintainer or to a service operated by this project.

## Information handled

When the user explicitly invokes a save action, the extension can pass selected
webpage text, an image of the selected visible area, a note entered in the
extension, the active tab title, and the chosen OneNote section identifier to
the local OneNote Native Messaging helper. The helper uses OneNote's local
desktop automation interface to create a page in that section. The helper does
not upload the content to a project server.

The extension stores the selected language and destination section preference
in Firefox's local extension storage. The Windows helper's executable and
Native Messaging registration are installed for the current Windows user.
Neither stores note content outside OneNote.

## OneNote synchronization

The extension and helper do not control OneNote account synchronization.
OneNote may sync a page according to the user's Microsoft account, OneNote
settings, and Microsoft services. Review Microsoft's OneNote privacy
information and account settings if synchronization is enabled.

## No unrelated browser data

The extension does not read Firefox saved passwords, autofill data, browsing
history, or page content for background collection. It only accesses selected
content in response to an explicit extension action. No analytics or
advertising trackers are included.

## Removing data

Saved notes can be deleted from OneNote. The language and destination
preferences can be removed by uninstalling the extension or clearing its
Firefox storage. Uninstalling the extension does not delete notes already
saved in OneNote or remove the separately installed Windows helper. The helper
can be removed using Windows Settings or by removing its current-user Native
Messaging registration.

## Gizlilik Politikası

Son güncelleme: 19 Ekim 2026

Firefox OneNote Quick Save, içeriği kullanıcının Windows bilgisayarında kurulu
OneNote masaüstü uygulamasına gönderir. Eklenti bu içeriği proje
geliştiricisine veya projenin işlettiği bir servise göndermez.

## İşlenen bilgiler

Kullanıcı kaydetme eylemini açıkça başlattığında eklenti; seçilmiş web sayfası
metnini, ekranda seçilen alanın görüntüsünü, eklentiye yazılan notu, etkin
sekmenin başlığını ve seçilen OneNote bölümünün kimliğini yerel OneNote Native
Messaging yardımcısına iletebilir. Yardımcı, OneNote'un yerel masaüstü
otomasyon arayüzünü kullanarak seçilen bölümde sayfa oluşturur. İçerik proje
sunucusuna yüklenmez.

Eklenti seçilen dili ve hedef bölüm tercihini Firefox'un yerel eklenti
depolamasında saklar. Windows yardımcısının programı ve Native Messaging
kaydı geçerli Windows kullanıcısı için kurulur. Not içeriği OneNote dışında
saklanmaz.

## OneNote eşitlemesi

Eklenti ve yardımcı, OneNote hesap eşitlemesini yönetmez. OneNote; Microsoft
hesabınıza, OneNote ayarlarınıza ve Microsoft hizmetlerine göre oluşturulan
sayfayı eşitleyebilir. Eşitleme açıksa Microsoft'un OneNote gizlilik bilgilerini
ve hesap ayarlarınızı inceleyin.

## İlgisiz tarayıcı verileri okunmaz

Eklenti Firefox kayıtlı parolalarını, otomatik doldurma verilerini, gezinme
geçmişini veya sayfa içeriğini arka planda toplamaz. Seçilen içeriğe yalnızca
kullanıcı bir eklenti eylemini açıkça başlattığında erişir. Analitik veya
reklam izleyicisi içermez.

## Verilerin silinmesi

Kaydedilmiş notlar OneNote'tan silinebilir. Dil ve hedef bölüm tercihleri
eklentiyi kaldırarak veya Firefox eklenti depolamasını temizleyerek silinebilir.
Eklentiyi kaldırmak, OneNote'a kaydedilmiş notları veya ayrıca kurulan Windows
yardımcısını silmez. Yardımcı Windows Ayarları üzerinden veya geçerli
kullanıcının Native Messaging kaydı kaldırılarak kaldırılabilir.
